# Refqat Al Mashaer — bilingual website concept

Private sales demonstration created 18 October 2026. Buildless HTML, CSS, and JavaScript. The deployable website is at the root of this folder. Open `index.html` to preview it; no build step is required.

Arabic is the default. `?lang=en` opens English; `?lang=ar` opens Arabic. The language preference is saved locally. All fonts and imagery are served locally.

## Behaviour

- Responsive layouts with native RTL/LTR switching, accessible mobile navigation, keyboard focus styles and reduced-motion support.
- Destination and arrival-date selectors populate the main enquiry form.
- Individual/family and agency/group enquiry modes, date-order and guest-count validation.
- An explicit review step creates a WhatsApp deep link for the selected published staff contact. No enquiry is transmitted by the site, no booking is confirmed, and no visitor details are stored in a database.
- FAQ accordions and bilingual privacy/source dialogs.
